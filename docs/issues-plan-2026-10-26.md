Source: the issues export of 2026-10-26 (14 reports, 11 from the DMS
UAT run "DMS UAT - October 2026" by Ellen Black, Kat Stojakovic and
Ben). Analysed 2026-10-26 against v0.76.0. Status column filled as

| 1 | Org folders take far too long to load (Ben) | The Folders pane walks the whole Organisation term set (depth 6, up to 6000 requests) before it paints anything, and on production that set holds 119 other sites. A finished walk is kept in the browser's storage for next time, so only the first load in a browser pays — but that first load is the one every tester meets, and a walk cut short or part-failed is never stored, so a slow term store means paying every time. | Paint the viewer's own branch FIRST: walk the site's subtree (the branch the pane opens on) and paint it, then walk the rest in the background for "Show other sites"; fetch sibling children in parallel (bounded) instead of one level at a time; keep a part-finished walk for the pane (it is display, not the sync) with the "deepest levels not loaded" line. | 4 h | |
